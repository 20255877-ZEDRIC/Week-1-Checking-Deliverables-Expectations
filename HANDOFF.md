# Project Handoff

## UX Project Proposal
**Project Title:** DriveHome
**Chosen Theme / Aesthetic:** Clean, modern mobile-app look: soft blue-grey backgrounds, white rounded cards, pill-shaped buttons, bright blue accent.

### User Problem
Used car buyers have to jump between many sites to compare prices, mileage, and specs, and cannot tell which listings are trustworthy.

### Target Audience
Adults aged 20-40 shopping for their first or next used car. They browse mostly on their phones and want quick filtering by budget and car type.

### Interface Goals
1. Fast filtering with search, budget, and category chips.
2. Clear comparison: name, mileage, and price at a glance on each card.
3. Easy detail view with key specs in simple tiles.
4. Familiar mobile patterns: bottom navigation, rounded cards, thumb-friendly buttons.

## Skeleton Layout Notes
- Screen 1 (Welcome): headline, description, hero image, page dots, prev/next buttons.
- Screen 2 (Browse): location bar, search, budget chips, category chips, car card, bottom navigation.
- Screen 3 (Details): back and heart buttons, car title and price, large image, key specs grid.
- Layout is built with flexbox and grid. All values come from CSS variables in `:root`.
